📧 Email via EmailJS (Free)
Get free key at emailjs.com → Account → API Keys
EmailJS Dashboard → Email Services → your Gmail service ID
EmailJS Dashboard → Email Templates. Template must use variables: {{to_email}}, {{to_name}}, {{otp_code}}, {{phone_number}}
📱 SMS via Fast2SMS (India, Free tier)
Get free key at fast2sms.com → Developer → API. Free plan: 200 SMS/month
⚠️ SMS works only for Indian (+91) numbers. For other countries only email OTP will be sent.
📋 Quick Setup Guide
EmailJS (5 min setup):
1. Sign up free at emailjs.com
2. Connect your Gmail account as a service
3. Create an email template with variables above
4. Copy your Public Key, Service ID & Template ID here

Fast2SMS (2 min setup):
1. Sign up free at fast2sms.com
2. Go to Developer → API → copy your key
3. Paste it above and enable SMS
